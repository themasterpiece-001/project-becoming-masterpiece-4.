PROJECT: BECOMING — THE MASTERPIECE
Installable personal growth and accountability PWA
===================================================

WHAT'S INCLUDED
- Daily goals checklist that resets automatically when the date changes.
- Daily completion percentage.
- Eight development pillars and a 90-day roadmap.
- First-week study plan and reading shelf.
- Morning/evening skincare checklist and product list.
- Daily journal and learning notes.
- Local progress storage, plus JSON export/import backup.
- Offline app shell after the first successful online load.

IMPORTANT ABOUT INSTALLATION
This is a Progressive Web App (PWA). For Android and Windows to offer the
normal "Install app" experience, the files must be hosted on an HTTPS website.
Opening index.html directly from the ZIP is useful for a quick preview, but
will NOT enable PWA installation or offline service-worker support.

EASIEST FREE PUBLISHING ROUTE: GITHUB PAGES
1. On a computer, sign in to GitHub and create a new public repository.
2. Upload all files in this folder to the repository's root (not the ZIP itself).
3. In the repository, open Settings > Pages.
4. Under "Build and deployment", choose "Deploy from a branch".
5. Choose the main branch and / (root), then Save.
6. Wait for GitHub Pages to publish the site. It will show you an HTTPS address.

INSTALL ON ANDROID
1. Open the published HTTPS address in Chrome.
2. Open the browser menu (three dots).
3. Choose "Install app" or "Add to Home screen".
4. Confirm. The app will appear on your home screen.

INSTALL ON WINDOWS
1. Open the published HTTPS address in Microsoft Edge or Chrome.
2. Select the install icon in the address bar, or open the browser menu.
3. Choose "Install this site as an app".
4. Confirm. You can launch it from the Start menu.

HOW PROGRESS IS SAVED
Progress is saved in the browser's local storage on each device. Android and
Windows do not automatically share the same data. Use Journal > Export backup
on one device, then Journal > Import backup on the other device to transfer it.
Keep backups before clearing browser data or changing devices.

DAILY REFRESH AND REMINDERS
The daily checklist creates a new dated record when the app is opened on a
new calendar day. Older dates remain saved. This app does not send a guaranteed
9 PM push notification while fully closed; set a daily 9:00 PM alarm/reminder
on your phone and open the app to complete your check-in.

CUSTOMISING THE PROGRAMME
The initial programme begins 12 November 2026. The 90-day counter is capped at
90. Daily goals, skincare steps, and pillar descriptions can be edited in app.js.
The app is a personal organisation tool, not medical advice.

PRIVACY
The app does not send your journal or progress to a server. Data stays in the
browser on the device where you use it, unless you export and transfer a backup.
